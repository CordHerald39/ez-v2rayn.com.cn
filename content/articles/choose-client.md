## 安装前只准备四件事

确认 Windows 系统类型，准备独立可写目录，保留原配置备份，再打开[开发者下载入口](/downloads/)。本指南使用 7.24.9 发行材料说明选择方法，不把网站域名当作官方授权。

## 选包时看完整文件名

普通 x64 Windows 在对应 64 位附件中选择；ARM64 Windows 则核对 arm64。86 表示另一架构选项，不是版本更新序号。文件名含 desktop 与不含 desktop 的 Windows 包属于不同界面实现，均应按开发者说明使用。

## 完整解压，不在压缩预览里启动

将 ZIP 解压到固定目录，保留全部随附文件。不要只拖出主 exe，也不要在压缩工具预览窗口直接双击运行。目录路径清楚、可写，才能在更新或备份时找到实际文件。

有旧版本时先保留它的完整副本，在新目录准备新版本，避免把不同版本文件混在一起。备份可能含私有订阅，应存放在你控制的位置。

## 第一次打开检查什么

检查实际版本号、主界面能否正常显示、日志有没有持续核心启动错误。程序打开就进入配置阶段；这时没有节点属于需要导入配置的正常准备状态，不要因此寻找来源不明的“一键修复包”。

| 问题 | 先检查 |
| --- | --- |
| 系统提示无法运行 | 架构、系统要求、文件完整性 |
| 提示缺少文件 | 是否完整解压，是否被其他软件隔离 |
| 打开的是旧版本 | 快捷方式目标与实际运行目录 |
| 核心持续报错 | 日志首个错误、文件结构与配置 |

完成后继续[订阅导入教程](/articles/import-subscription/)。不建议在尚未确认来源时关闭安全防护，也不需要先开启所有高级功能。
