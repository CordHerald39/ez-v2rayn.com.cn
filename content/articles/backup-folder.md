> 核验于 2026-09-20：本文基于开发者资料与发行记录整理；未完成客户端 GUI、真实订阅或设备实测。以下验收标准是操作目标，不是已跑出的测试结果。

## 先找到真实目录

开发者文档说明 ZIP 便携包在本文件夹存储文件。桌面快捷方式只是入口，复制它不会备份程序和配置。检查快捷方式目标或实际运行目录，确认是哪一份版本在使用。

## 在稳定状态保存副本

先通过客户端正常停止并退出，避免复制过程中持续写入。将完整相关目录保存到单独位置，并标注日期、客户端版本与系统。备份可能包含订阅和节点凭据，应放在你控制的存储中。

对于系统安装包，数据位置可能不同，不能照抄便携目录方法。先按对应平台说明找实际数据目录，再决定保存哪些文件。

## 备份是否可用需要验证

在不覆盖原件的独立目录确认备份能被相应版本读取。先比较分组、当前项和重要设置，再检查实际请求。只看到 ZIP 能解压，不能证明配置已经可恢复。

| 应记录 | 原因 |
| --- | --- |
| 版本与备份日期 | 判断恢复的兼容性与时点 |
| 程序与配置位置 | 避免恢复到另一份旧目录 |
| 当前接管设置 | 恢复配置不一定恢复系统状态 |
| 验证结果 | 区分已验证备份与仅复制文件 |

升级失败时保留新日志，再用已确认适配的副本恢复。不要把新格式文件反复覆盖到唯一旧备份里。[回到配置指南](/configuration/)。
